Why it matters: Levi doesn't want fellows going through a browser, and the two ways onto the server differ on exactly that.
- Tailscale: install an app, sign in through a browser once during setup, then type ssh nt from then on; works from phones. Needs the network rule in T101 first.
- Cloudflare (today's ssh nt): install a developer tool (cloudflared), then sign in through a browser each time the Cloudflare session runs out (the length is a setting; a day is common).

The stricter step Levi picked on 8/12 for later (Cloudflare short-lived certificates) depends on that same browser sign-in. If "no browser" is firm, the stricter step changes to Tailscale's device identity or hardware-backed keys.

Decide: which way fellows use, and whether the 8/12 stricter step stands.

What it unblocks: the setup kit (T104), the register-a-person procedure (T103), the stricter check (T126).

Intent: non-coders get in with one command, without a browser if possible.
