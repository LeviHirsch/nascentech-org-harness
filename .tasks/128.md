Levi's preferred eventual design (10/2): "since their login routes them as a user to a profile, theoretically that profile could be a sub-environment as needed for storing that stuff, but I realize that that may be somewhat involved for the moment."

So a developer's server profile (users/<name>/) would hold their git identity and their secrets, such as a GitHub login. On the shared account anything stored there is readable by everyone signed in, so real privacy needs separate server accounts (T127).

For now developers work on their own laptops (T121).

Intent: a dev teammate's secrets stay theirs.
