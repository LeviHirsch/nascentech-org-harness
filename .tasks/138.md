Built 10/3 as clv setup, published in the public repo LeviHirsch/homebrew-tap, folder clv/ (v0.1.4-kit). The one-line installer runs it:
- Mac and Linux: curl -fsSL https://raw.githubusercontent.com/LeviHirsch/homebrew-tap/main/clv/install.sh | bash
- Windows: irm https://raw.githubusercontent.com/LeviHirsch/homebrew-tap/main/clv/install.ps1 | iex

What it does, with no sudo:
- installs clv and nt into ~/.collevity/bin, and downloads cloudflared directly (no Homebrew);
- asks the person's first name and makes ~/.ssh/id_ed25519_nt (no passphrase in v0; T153);
- writes Host nt in ~/.ssh/config.d/nt through one Include line, after backing up the SSH config;
- pins the mini's host key in ~/.collevity/known_hosts, with strict checking;
- stores no sign-in credential: cloudflared opens the browser for Google sign-in about once a week (T100);
- prints the ssh-ed25519 line to text to Levi (clv key shows it again), and starts a fresh shell so nt works at once.

Safe to re-run; it refuses to overwrite a clv or a Host nt it didn't install. Also built: clv update, clv uninstall, clv help, clv version.

Ruled (Levi 10/3): "the middle path at least seems like a good idea": clv is the main command, nt its shortcut, installed under ~/.collevity.

Done when: on a clean laptop, one run leaves the key and the nt entry in place and prints the public key; a second run changes nothing. Met on Mac 10/3: Levi ran it end to end on his MacBook Air and reached the mini as airtest. Linux is untested on a real machine (T146), and Windows too (T141).

Intent: "a way for holding the login creds and setting up the key", in one step.
