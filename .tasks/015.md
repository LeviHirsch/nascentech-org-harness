Built 10/3 as nt-register, Levi's admin tool in LeviHirsch/homebrew-tap (clv/nt-register), run from his laptop:
- nt-register <name> "<the ssh-ed25519 line they texted>" checks the name (lowercase letters, digits, dashes) and that the key is one valid ed25519 line, backs up the mini's authorized_keys, and appends the line binding the key to the name through clv-login; a key already present is refused;
- nt-register --remove <name> backs up, then deletes every line bound to that name;
- --dry-run shows what would change and connects to nothing.
It never issues keys. Levi registered his MacBook Air's key with it on 10/3 and reached the mini as airtest.

Left:
- the key line carries no-agent-forwarding only, so port forwarding is still allowed;
- --remove levi is unguarded, so Levi could remove his own way in.

Done when: both are closed, and a bad key or name is still refused with nothing changed.

Intent: adding or removing a person is one safe, repeatable command for Levi.
