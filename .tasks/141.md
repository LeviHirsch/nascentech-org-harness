Homebrew is Mac-only. Windows: cloudflared through winget, the built-in OpenSSH, and a PowerShell version of setup (credential in Windows Credential Manager). Chromebook: only through its Linux environment (the cloudflared Debian package and the same setup script). Phones can't run cloudflared, so phone access stays on Tailscale (Levi's own path) and isn't offered to fellows for now.
