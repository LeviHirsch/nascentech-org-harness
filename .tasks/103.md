Registering someone has a tool now (nt-register, T15) but no written procedure and no record. Write it as a board flow ("register a person") and run it once per person:
- the person runs the kit's one-line install (T138) and texts Levi the ssh-ed25519 line it prints (clv key shows it again);
- pick their name (the T99 rule; nt-register takes lowercase letters, digits and dashes);
- run nt-register <name> "<that line>" (--dry-run first shows the change and the key's fingerprint); it backs up authorized_keys and binds the key to the name;
- make sure their @nascentech.com account passes the Cloudflare sign-in (T100, T102);
- link their Google account (T5);
- the person types nt and confirms they see their own name in clv whoami.

Removing someone: take them out of Google Workspace and run nt-register --remove <name>; the two gaps that leaves are T145. Do one removal to prove it.

Each run's record is the access log until T87 records registration as an event.

Done when: the flow exists, every current person has a run, and one removal has been done and checked.

Intent: "register a user on the server for the first time" is a known, recorded procedure, and so is taking access away.
