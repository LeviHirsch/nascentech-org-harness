The 8/8 SSH SOP on the shared drive (01_EXEC/protocols) is the model: split by audience, copy-paste steps, a clear success check, a way to revoke. Three things must change before anyone uses it:
- its admin part adds the key without binding it to a name, which creates nameless keys;
- it uses the name nascentech-server instead of nt;
- it covers Cloudflare only and has no Windows path.

Revise it: one setup that makes a dedicated key, saves it to the Keychain, adds the nt entry, and shows the public key to send; then ssh nt from then on. Mac and Windows (confirm which laptops people have); phones through Termius.

Done when: one fellow completes it unaided and sees their own name in clv whoami.

Intent: non-coders set up from the terminal once, then get in with one command.
