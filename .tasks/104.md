The human-readable guide around the client kit, which does the technical steps (T138, T139). Model it on the 8/8 SSH SOP on the shared drive (01_EXEC/protocols): split by audience, copy-paste steps, a clear success check, a way to revoke. The kit's README (LeviHirsch/homebrew-tap, clv/README.md) already has the fellow's steps:
1. paste the one-line install for your OS and give your first name;
2. text Levi the whole line starting ssh-ed25519 that it prints;
3. when Levi says you're registered (he runs nt-register, T103), type nt; a browser opens the first time and about once a week: sign in with your @nascentech.com Google account;
4. on the server, clv whoami shows your name.

Per OS: Mac is tested (Levi's MacBook Air, 10/3); Windows (T141) and Linux and Chromebook (T146) have installers that still need a real-machine test. Phones stay outside the kit.

The SOP's admin part must also change: it adds keys without binding them to a name, which creates nameless keys, and it uses the name nascentech-server instead of nt. nt-register replaces it.

Ruled (Levi 10/2): "not everyone will have macos... so it has to be agnostic ultimately."

Done when: one fellow completes it unaided and sees their own name in clv whoami.

Intent: non-coders set up from the terminal once, then get in with one command.
