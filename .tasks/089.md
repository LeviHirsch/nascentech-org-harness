Shipped (2026-08-16): deploy-mini now discovers tools from bin/ (any executable) instead of a hardcoded list, so a new tool can no longer be silently skipped. Dropped the now-dead missing-from-repo branch. Also fixed a latent set -e bug this surfaced: the discovery function inherited the exit status of its last test, which fails whenever bin/ ends in a non-executable, killing the script with no output at all.
