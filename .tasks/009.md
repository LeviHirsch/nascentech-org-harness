One append-only store on the mini. Every record has actor, method, session_id, kind. Personal laptop lake stays separate. none is allowed and labeled.

Decision: one env lake, filtered views, not per-user lakes. Org-minimal schema (not a copy of the personal laptop lake). Path under ~/nascentech-env/ on local disk. Fields: principal, actor, subject, method, session_id, kind. none is labeled, never defaulted to a person.

Decision: agent writes set actor to the agent and provenance/method honestly. Never stamp author=user for an agent (team-server 0.5 + Dropper D-002).

Decision: credibility fields allowed on records (confidence, provenance). Agent writes are provenance=ai. Human capture is user unless marked. Not a full cascade.

Decision: may reuse useful personal-lake field names (source, tags, actual|projected). Must not default author=user. Must not write the personal laptop lake. Org-minimal first.

Decision (dry-run vs personal lake): personal keys are author, created_at, id, source, text, optional context. Org-minimal: id, created_at, source, text, principal, actor, subject, method, session_id, kind; optional context, confidence, provenance. Never a field named author defaulting to user.
