An organizational context engine on the NascenTech server: it identifies a person at entry and routes behavior, AI included, by who they are. NascenTech is the first full-stack example.

Reworked 10/2 into workstreams that run side by side and phases that run in order.

Workstreams (each an umbrella; areas match, for the by-area view):
- Front door (T21): sign in, register, one-command entry.
- Shared base (T130): the environment everyone gets.
- Own space (T131): sign-in routes each person to their own environment.
- Own dropper (T18): each person's prompts and ideas, captured and visible.
- House rules (T132): trust first, guided permissions.
- Google as you (T16): the server acts in Google only as the signed-in person.
- Know your tools (T19): people know what they can do.
- Contributor path (T133): a dev teammate commits from their own profile.
- Later: Lock-down (T134), Org memory (T135).

Phases:
1. Open the door: Shared base fixes, Front door, House rules.
2. Settle in: Own space, Own dropper, Know your tools.
3. Act as yourself: Google as you, Contributor path.
4. Lock down: starts when a trigger in T111 fires.

Decided (Levi 10/2): trust the cohort now; lock down later.

Open decisions, most important first: T100, T105, T115, T111, T109, T121, T96, T119, T118.

Out of scope (AGENTS.md): client UI, graph database, ACL product, Dropper rewrite.

The first identity cut (T4) was verified 10/2. Earlier revisions of this umbrella are in git history.
