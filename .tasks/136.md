- The laptop kit installs nt (sign in; extra arguments pass through to ssh, like Levi's ssh-nt) and nt-setup (run once). nt-setup rather than "nt setup", because nt <args> already means "run this on the server".
- clv stays the server's identity tool (clv whoami). Levi's personal laptop clv is untouched; he hopes the tools converge into one someday, so nothing should be designed to block that.
- Which tap publishes the kit is still undecided; ask Levi when T140 is built.

Intent: the command fellows type is short, memorable, and means one thing.

Merging the three clv programs into one codebase is its own task.
