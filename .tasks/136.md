Why it matters: the kit puts commands on every fellow's laptop, and the name clv already means two different programs. On Levi's laptop it is his personal list tool (clv 0.1.0: list, add, show, rm); on the server it is the identity check (clv whoami). A third meaning would make help, guides and AI instructions ambiguous.

Options for the name:
- one clv everywhere: clv setup and clv login on laptops, clv whoami on the server. Levi's personal list tool gets a new name;
- leave clv to the server: the kit installs plain commands such as nt (sign in) and nt-setup, matching ssh nt and Levi's ssh-nt.

Options for where: Levi's public tap (levihirsch/tap, which holds mark-this-down), or a new NascenTech or Collevity tap. A tap has to be public because fellows have no GitHub login, so the kit can't contain anything secret either way.

What it unblocks: the package (T140).

Intent: the command fellows type is short, memorable, and means one thing.
