Requirement (Levi): non-coders get set up terminal-side, register a key, then get in with one command. On 10/2 he pointed at his own setup: "ssh nt and I'm golden… the login is as simple as one terminal command… maybe there is a homebrew tap we set up to get them the .collevity or .clv clientside something or other… such that it gives a way for holding the login creds and setting up the key." And: "What is the log-in flow and how do they 'register a user on the server for the first time'?"

Levi's setup (10/2): Host nt in ~/.ssh/config runs cloudflared as its proxy; cloudflared opens a browser by itself when the Cloudflare session runs out and caches the result, so day to day it is one command (plus an ssh-nt shortcut).

The flow for everyone else:
1. Install the client kit (T140) and run its setup once (T138): key, Keychain, the nt entry, the sign-in credential (T100), and the public key ready to send.
2. Levi runs register-a-person (T103).
3. The person types one command (T139), sees their own name, and lands in their own space (T131).

Exists: clv-login binds a key to a name (8/12); Levi's laptop and phone keys are bound; per-person folders are made at first sign-in; the 8/8 SOP is the model guide.

Gaps (10/2): nameless keys and password login skip identity (T98); any text is accepted as a name (T99); registration has no record (T103); the SOP would create nameless keys (T104); nobody has checked who Cloudflare admits (T102); there is no kit yet.

Decided: per-person SSH keys now, a stricter check later (Levi 8/12); identity is read only through clv whoami; Cloudflare stays the way in, through a client kit, with Tailscale as the noted alternative (Levi 10/2).

Open: T100 (browser about once a month, or never); T136 (the command's name and where the kit is published).

Done when: a fellow on a clean Mac installs the kit, runs setup once, is registered, and from then on gets in with one command as themselves; each registration is recorded; one removal has been tested.

Manual interim: until T15 and T87 land, registration is Levi running T103 by hand.

Later: T141 (Windows, Chromebook); T60 (sign-in at the mini's own keyboard); the stricter check in Lock-down (T126).

Intent: everyone gets in with one command as themselves, the way Levi does, and adding or removing a person is a known, recorded step.
